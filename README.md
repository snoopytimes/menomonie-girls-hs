# Menomonie Mustangs — Coaching Resources

A collection of tools and guides for the Menomonie High School girls varsity soccer program.

## What's in here

| Folder | Type | Description |
|--------|------|-------------|
| `interactive-viz/field-shape/` | Interactive HTML | Pressing and defensive shape viewer for the 4-3-3 sweeper/libero system |

More tools will be added over time covering practice plans, position guides, and player feedback resources.

## How to use

Each tool is self-contained. Open any `index.html` directly in a browser, or deploy it to a hosting service like Netlify or GitHub Pages for easy sharing with players and staff.

## System

- **Formation:** 4-3-3
- **Defensive system:** Sweeper / Libero
